# Dynamic context: ON

DYNAMIC CONTEXT MODE: the context limit ({CONTEXT_LIMIT} tokens, the slider
value) is your LIVE budget. Work with the RECENT context: keep the latest
state in mind, summarize/compact older parts yourself, and drop what is no
longer relevant to stay inside the budget. This mode cannot run together
with the thinking-context limit — the thinking-context limit is hard-turned
OFF while dynamic context is ON.
